# EDA House Price Analysis

## Project Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on the House Price dataset to understand the data, identify patterns, detect outliers, and analyze relationships between features.

---

## Tools and Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Steps Performed

1. Imported required libraries
2. Loaded the dataset
3. Checked dataset information and data types
4. Analyzed missing values
5. Checked duplicate values
6. Generated summary statistics
7. Created correlation heatmap
8. Visualized data using histograms
9. Detected outliers using boxplots
10. Created scatter plots for feature relationships
11. Generated insights from the analysis

---

## Visualizations

* Correlation Heatmap
* Histograms
* Boxplots
* Scatter Plot

---

## Key Insights

* Some features are highly correlated with house prices.
* The dataset contains outliers in several columns.
* Histograms show the distribution of numerical features.
* Scatter plots help understand relationships between variables.
* Correlation heatmap clearly shows positive and negative relationships among features.

---

## Conclusion

This project helped in understanding the structure of the dataset and identifying important patterns and relationships between variables using Exploratory Data Analysis techniques.
